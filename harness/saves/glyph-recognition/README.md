# Real engine glyph-recognition controls

Six selected native saves generated twice identically at tag `m4` with
`generate.py --glyph-recognition`. The original low-supply and prelaid-ring
saves match synthetic-tactics byte for byte. No Borg state is seeded.

The visible Rune, decoy, revealed pit, hidden Rune and empty-floor controls
have nine known Rune scrolls, below the builder's casting threshold. The
hidden Rune is behind an opaque wall within the panel; its real engine
presence must not become Borg glyph knowledge. The ring has 24 warding
glyphs and 20 scrolls. These are constructed level50/depth100 characters,
with the same kit and isolated Morgoth preparation conditions as M4.

Use `SAVE_ROOT=harness/saves/glyph-recognition` with suite glyph-recognition.
SOURCES.json pins each selected save and generator.json records the native
constructor and original object hashes. The source checkpoint is M4;
the same saved bytes drive the before and corrected C/Rust replays.
