# Impact v15R

This release carries the better-borg-c v14 fixes and v15 reconciliation
into Borg-rs and updates the vendored Angband engine to `574b618c3`.

- Retreat avoids first steps next to faster monsters. Immediate escape
  skips delayed Deep Descent, and either teleport capability can enable
  the landing check.
- Mind Blast danger accounts for damage and confusion. Rubble removal
  clears the in-bounds neighborhood in darkness. Electricity resistance
  names the right element in the log, and equipment slays keep the
  highest multiplier across slots.

All 18 native fixture cases passed. The Rust and C Borgs matched on
keypresses, messages, and engine state in all 45 full-suite scenarios and
all 3 smoke scenarios. [Accepted carry and validation](https://github.com/diegoami/borg-rs/pull/109)

For Linux x86-64, extract the binary archive, change to the extracted
directory, and run `./angband -mx11`. The archive includes the game data.
Install the X11 bitmap fonts (`xfonts-base` on Debian and Ubuntu).
Create or load a character, then press Ctrl-Z followed by z to start the Borg.

The source archive contains the standalone source tree. The patch applies
to Borg-rs commit `8c5d000a58e9ddca1f1954ab9552e505856b313f`.
